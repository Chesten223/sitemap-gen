FAQ

What is a sitemap.xml and why do I need one?
A sitemap.xml is a file that lists all the URLs on your website to help search engines like Google and Bing discover and crawl your pages. It's essential for SEO because it ensures search engines don't miss important pages, especially on new or large sites. Sitemaps also let you specify when pages were last modified and how often they change.
What are priority and changefreq values?
Priority (0.1–1.0) tells search engines how important a page is relative to other pages on your site. Your homepage is typically 1.0, while less important pages are lower.

Changefreq tells search engines how often a page is likely to change (always, hourly, daily, weekly, monthly, yearly, never). This is a hint, not a command — search engines may crawl more or less frequently.
Is there a limit to how many URLs I can include?
The official sitemap protocol allows up to 50,000 URLs per sitemap file and a maximum file size of 50 MB (uncompressed). This tool will warn you if you exceed these limits. For sites with more than 50,000 URLs, you should create a sitemap index file that links to multiple smaller sitemaps.
